> **建立时间**：2026-04-25
> **主人**：小黎（上海电力大学大一，集成电路转电气）
> **目标**：建立科研底层认知，为本科科研/竞赛/申硕打基础

---

## 核心理念

学部老师的话：「科研论文就是包装好的八股文。先看100篇文献培养科研感觉。」

**百篇文献阅读法**：
- 大部分论文：看标题+摘要→知道七八成→过滤
- 顶刊论文：逐字逐句精读→甚至能背下一句话→下次写论文直接调用
- 顶刊开源代码：必须读，这是最值钱的"顶层设计"
- 引用链追踪：读顶刊引用的顶刊→理解"为什么要引用"→找到创新方向

## 阅读工作流

```
论文找到
  │
  ├── 非顶刊 → 看标题+摘要 → 判断是否相关
  │     ├── 不相关 → 跳过
  │     └── 相关 → 读introduction+结论 → 决定是否精读
  │
  └── 顶刊/顶会
        ├── 先读标题+摘要（判断是否相关）
        ├── 相关 → 逐字精读全文
        ├── 拆解：为什么这篇能发顶刊？
        ├── 追踪引用：它引用了哪些论文？为什么引？
        └── 记录：可用金句/方法/数据到认知库
```

## 关键原则

1. **不是所有论文都值得读**——100篇里可能只有10篇值得精读
2. **顶刊一篇顶十篇**——时间花在刀刃上
3. **开源代码比论文正文更值钱**——看作者怎么实现的
4. **引用链就是创新地图**——看谁引了谁，就能找到研究空白
5. **精读到能背下一句话**——下次写论文时的素材库
