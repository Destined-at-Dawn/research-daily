# 科研日报复盘体系

> 定期回顾科研日报的效果和质量，不断优化筛选标准和输出方式。

---

## 为什么需要复盘？

日报的质量不是一开始就完美的。需要不断调试：
- 筛选标准太宽 → 日报太长，读不完
- 筛选标准太严 → 错过重要论文
- 决策理由不够好 → 用户不理解"为什么读"
- 领域关键词不准 → 不相关论文太多

**复盘频率**：每周一次（周日晚上）

---

## 复盘模板

```markdown
# 科研日报复盘 | 第 X 周（{日期区间}）

## 本周产出
- 共产出 X 份日报
- 累计处理论文 X 篇
- S 级论文 X 篇 / A 级论文 X 篇

## 质量自检

### 筛选标准
- 标准太严/太松/刚好？
- 有没有错过重要的论文？
- 有没有收录太多低质量论文？

### 决策理由
- "为什么值得读"的说服力如何？
- 大一视角够不够？
- 有没有改进空间？

### 覆盖度
- AI/IC/EE 三个方向比例是否合理？
- 有没有偏科？
- 用户最近关注的方向是否覆盖到了？

## 关键词更新
- 本周新发现的关键词：
- 需要新增/删除的关键词：
- 用户反馈的新方向：

## 信息源
- 当前信息源（arXiv）是否够用？
- 是否需要接入 IEEE/SCI？
- 有没有发现新的好源？

## 下周计划
- [ ] 调整筛选标准（如有）
- [ ] 更新关键词
- [ ] 尝试接入新源（如有）
- [ ] 优化决策理由写法
```

---

## 使用方式

```
第 1 次复盘（7 天后）：执行首次复盘
以后每周日自动执行

用户说"复盘"→ AI 自动读取本周产出 → 生成复盘报告
```
