# 与科研认知系统的衔接机制

> 科研日报（获取前沿动态）→ 科研认知系统（深度消化）的完整转化链路。

---

## 为什么需要衔接？

```
科研日报                         科研认知系统
─────────                       ────────────
快速浏览每日前沿                  深度消化高质量论文
"今天有什么新东西？"               "这篇论文为什么牛？"
筛选器 + 导航员                   精读器 + 知识库
```

两个系统各司其职，但必须打通：**日报发现的好论文，不能看了就忘，必须进入认知系统沉淀下来。**

---

## 转化链路

```
日报产出
  │
  ├── S 级论文 → 标记"待精读" → 用户确认 → 建立精读文件
  │                              ↓
  │                         科研认知/readings/{论文缩写}_{日期}.md
  │                              ↓
  │                         S/A/B 精读流程（文献阅读体系.md）
  │                              ↓
  │                         提炼金句/方法/数据 → 认知之书对应章节
  │
  ├── A 级论文 → 记录概要 → 必要时升级精读
  │
  ├── 技术洞察 → 可转化为公众号文章素材
  │
  └── 学习笔记 → 自动补充认知之书对应章节
```

---

## S 级论文精读流程

当用户说"精读这篇"时，自动执行：

```
1. 创建精读文件
   → 科研认知/readings/{领域}_{论文缩写}_{YYYYMMDD}.md
   → 包含论文基本信息（标题/作者/来源/摘要）

2. 执行文献阅读体系中的精读流程
   → 读全文（如有）
   → 拆解：为什么能发顶刊？
   → 追踪引用链
   → 分析开源代码（如有）

3. 产出精读笔记
   → 核心金句（可背诵）
   → 可用的方法/数据/图表
   → 个人理解 + 应用思路

4. 归档到认知系统
   → 金句 → 认知之书对应章节
   → 方法 → 公众号/自己/技法吸收记录.md
   → 论文元数据 → 科研认知/readings/ 索引
```
