```

https://ieeexplore.ieee.org/search/searchresult.jsp?queryText={关键词}

# 注意：IEEE 需要学校 VPN / 图书馆代理
学校图书馆电子资源：http://lib.shiep.edu.cn/
```

## 五、当前实际可用的采集流程

> 目前阶段（v1.0），实际可用的源是 arXiv（Web Fetch 可直接访问）。
> IEEE Xplore 和 SCI 期刊需要学校资源，逐步扩展。

```
每天执行：
1. 依次访问 arXiv 3 个核心类别（cs.AI, cs.LG, eess.SY）
2. 读取标题+摘要 → 初筛
3. 生成日报

未来扩展：
2.0：接入 IEEE Xplore（学校 VPN）
3.0：接入 SCI 期刊（独立访问）
4.0：RSS 聚合 + 自动推送
```
