# S/A/B 论文分级标准

> 与 `科研认知/文献阅读体系.md` 对齐的论文分级标准。
> 每一篇进入日报的论文都会按此标准分级。

---

## 分级总览

| 等级 | 标签 | 含义 | 日报中展示 | 后续动作 |
|------|------|------|-----------|---------|
| **S** | 🔴 | 顶刊/顶会 + 重大突破 + 与研究方向直接相关 | 精读推荐（含"为什么能发顶刊"拆解） | 自动标记"待精读" |
| **A** | 🟡 | 高质量 + 相关/方法可学 | 值得一读（含核心要点 + 决策理由） | 记录到学习笔记 |
| **B** | 🔵 | 普通/略相关 | 一句话记录或暂不收录 | 跳过 |

---

## S 级标准（🔴 精读推荐）

必须同时满足**至少 3 项**：

| 维度 | 标准 |
|------|------|
| ① 论文出处 | 顶刊（Nature/Science 子刊、IEEE JSSC/TPEL、NeurIPS/ICML 等）或 top 5% 高引 arXiv |
| ② 创新程度 | 提出了新方法/新范式/新理论，不是 incremental work |
| ③ 领域相关性 | 匹配至少 1 个 ⭐⭐⭐ 关键词，或者 3 个以上普通关键词 |
| ④ 影响力 | 发表后 30 天内被广泛讨论（Twitter 引用、媒体报道、GitHub 高星） |
| ⑤ 可学性 | 大一学生能理解核心思想（即使不懂技术细节） |

**日常判断简化**：
```
顶刊 + 重大突破 + 与我相关 = S 级
顶刊 + 重大突破 + 不直接相关 = 先记 A 级
顶刊 + 小改进 + 与我相关 = A 级
```

---

## A 级标准（🟡 值得一读）

满足**至少 2 项**：

| 维度 | 标准 |
|------|------|
| ① 论文出处 | 高质量期刊/会议（IEEE Trans., AAAI, ICLR 等）或 top 20% arXiv |
| ② 创新程度 | 有明确的改进/新应用，虽然不是颠覆性创新 |
| ③ 领域相关性 | 匹配至少 1 个普通关键词，或跨领域启发 |
| ④ 方法可学 | 方法/框架有通用性，可以迁移到其他方向 |
| ⑤ 可学性 | 大一学生读完摘要能大致理解做了什么 |

---

## B 级标准（🔵 一句话跳过）

满足以下任一：

| 维度 | 标准 |
|------|------|
| 论文出处 | 普通期刊/arXiv preprint |
| 相关性 | 关键词匹配 0 个，且非顶刊 |
| 创新程度 | 纯粹的 incremental work（换数据集跑了一遍） |
| 可学性 | 需要大量前置知识才能理解，对大一学生不友好 |

**B 级论文在日报中**：只记录标题，不展开。除非特别多同类论文集中出现（提示趋势），否则直接跳过。

---

## 分级打分的简化流程

```
读标题+摘要
  │
  ├── 顶刊/顶会吗？
  │     ├── 是 → 暂定 S/A（看创新度和相关性）
  │     └── 否 → 暂定 A/B（看相关性和可学性）
  │
  ├── 与三领域相关吗？
  │     ├── 高度相关（⭐️⭐️⭐️ 关键词命中） → 升一档
  │     ├── 中度相关（普通关键词命中） → 维持
  │     └── 不相关 → 降一档或 B 级
  │
  ├── 创新吗？
  │     ├── 新方法/新范式 → 升一档
  │     └── 小改进/换数据集 → 降一档
  │
  └── 大一能学吗？
        ├── 核心思想可理解 → 维持
        └── 完全看不懂 → 降一档
```

## 日报中的展示示例

```
🔴 [S] Attention Is All You Need
- 一句话：提出了一种不用 RNN 只用注意力机制的序列建模方法
- 为什么能发顶刊：彻底改变了 NLP 领域的基础架构，影响力巨大
- 决策：⭐⭐⭐⭐⭐ 必精读——这篇是理解现代 AI 的基石
- 来源：https://arxiv.org/abs/1706.03762

🟡 [A] EfficientNet: Rethinking Model Scaling
- 一句话：提出了一种更高效的 CNN 缩放方法
- 决策：⭐⭐⭐ 值得读——方法经典，大一可以理解核心思想
- 来源：https://arxiv.org/abs/1905.11946

🔵 [B] 某论文标题
- 一句话：常规改进
- 决策：跳过
```

## 与科研认知系统的关联

| 日报分级 | 科研认知系统处理 |
|---------|----------------|
| S 级 | → readings/ 创建精读文件 → 按文献阅读体系.md 的精读流程执行 |
| A 级 | → readings/ 创建记录（标题+摘要+一句话） → 后续可升级为精读 |
| B 级 | → 不进入 readings/ |
