## 六、使用方式

### 筛选规则

```
1. 标题/摘要中出现上述关键词 → 自动标记为"相关"，进入 S/A/B 分级
2. 匹配 3 个或以上关键词 → 高优先级
3. 出现 ⭐⭐⭐ 标记的关键词 → 自动升一档分级
4. 完全无匹配 → 如果非顶刊 → 跳过
```

### 更新规则

```
1. 用户说"更新关键词"或"我最近看 XXX" → 自动更新此文件
2. 每周复盘时检查关键词是否需要更新
3. 发现新方向/新技术 → 追加至对应板块
4. 中文+英文都要记录，便于搜索匹配
```
