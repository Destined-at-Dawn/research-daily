# 科研日报系统

> **建立时间**：2026-04-25
> **主人**：项目作者（某高校在读）
> **目标**：每天 5 分钟，掌握 IC+EE+AI 三大领域前沿动态
> **核心理念**：不做信息搬运工，做你的"论文导航员"

---

## 解决什么问题

调研了 4 个科研日报工具（news-bot、daily-arXiv-ai-enhanced、ChatDailyPapers、Arxiv-tracker），发现一个共同空白：

**所有工具都在做"获取更多信息"，没人做"帮你决定读不读"。**

科研日报系统 = 三级火箭架构（获取 → 筛选 → 决策），定位在"决策层"——不只会告诉你今天有什么论文，更会告诉你 **这篇论文为什么值得/不值得你读**。

---

## 日报内容模块

每日产出包含以下板块：

| 模块 | 内容 | 筛选标准 |
|------|------|---------|
| 🔥 **今日突破** | 1-2 条顶刊/顶会重大突破 | 影响力大 + 与三领域直接相关 |
| 📄 **前沿论文** | 3-5 篇 S/A 级论文 | 按 S/A/B 分级，含决策理由 |
| 💡 **技术洞察** | 论文间联系/趋势/交叉方向 | 引用链追踪 + 跨领域观察 |
| 🛠️ **工具与代码** | 开源工具/复现代码 | 可复现/可学习 |
| 📅 **明日关注** | 截稿/会议/事件预告 | 与三领域相关 |
| 📊 **学习笔记** | 可汇入科研认知系统的提炼 | 从论文中提的可学点 |

## 工作流

```
用户说"生成今日科研日报"
  │
  ▼
Skill 自动激活 → 访问 arXiv 等源 → 采集 24h 论文
  │
  ▼
标题+摘要快速筛选 → S/A/B 分级
  │
  ▼
每篇 S/A 论文生成决策理由
  │
  ▼
结构化输出 → 存入产出/
  │
  ▼
S 级自动标记"待精读" → 关联科研认知系统
```

---

## 关联系统

| 日报输出 | 流向 | 触发条件 |
|---------|------|---------|
| S 级论文 | → 科研认知/readings/ 精读笔记 | 你说"这篇精读" |
| 技术洞察 | → 公众号/产出/ 文章素材 | 你说"写成文章" |
| 认知笔记 | → 认知之书/ 对应章节 | 自动补充 |
| 关键词演变 | → 配置/领域关键词.md 更新 | 你说"更新关键词" |

## 使用方式

```markdown
# 快速开始
你说："生成今日科研日报"
AI 自动：调用 Skill → 采集信息 → 分级 → 输出 → 存档

# 精读论文
你说："精读这篇 S 级论文"
AI 自动：创建 科研认知/readings/{论文名}.md 精读笔记

# 转化为内容
你说："把今天的技术洞察写成文章"
AI 自动：转到 公众号/ 内容创作流程

# 更新关键词
你说："我最近在看 XXX 方向，更新关键词"
AI 自动：更新 配置/领域关键词.md
```

> **先定个小目标**：前 30 天，每天产出一份 5 分钟可读完的科研日报，积累从"看热闹"到"看出门道"的科研感觉。
